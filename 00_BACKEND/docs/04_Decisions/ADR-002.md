# ADR-002 — Abstraksi Service Layer Wajib

## Status

Diterima.

> **Catatan verifikasi 2026-10-12:** keputusan masih berlaku. Lokasi service layer runtime adalah root `src/services/**` (TypeScript); `00_BACKEND/src/services/**` adalah implementasi referensi yang tidak diimpor frontend. Satu pelanggaran diketahui (lihat Consequences).

## Context

- Memanggil Appwrite SDK langsung dari halaman menyebar logika akses data ke seluruh UI.
- Hal ini mempersulit pengujian, penggantian implementasi, dan menjaga konsistensi query/permission.

## Decision

Seluruh akses Appwrite **wajib** melalui service layer:

```text
Route/Component → Service → Appwrite SDK
```

Komponen route (`page.jsx`) / komponen lain tidak boleh memanggil Appwrite SDK secara langsung.

## Consequences

- (+) UI terisolasi dari detail SDK; mudah diuji dan diganti.
- (+) Logika query/permission terpusat dan konsisten.
- (−) Ada lapisan tambahan yang harus dibuat untuk setiap domain (authService, campaignService, dll.).
- Ditegakkan sebagai aturan kerja: [50_Project_Rules.md](../00_Project/50_Project_Rules.md).

### Catatan implementasi (2026-10-12)

- Service runtime aplikasi web ada di root `src/services/` per domain/peran: `auth/`, `umkm/`, `creator/`, `shared/`, `chatbot/`. Pola: facade (`*.service.ts`, termasuk mode mock `DATA_SOURCE_CONFIG.useMockData`) → adapter Appwrite (`*-appwrite.service.ts`) → wrapper SDK di `src/lib/appwrite/` (`databases`, `account`, `storage`, `functions.executeFunction`). Hasil dibungkus `ServiceResult` (`src/services/shared/service-result.ts`).
- Admin app terpisah (`admin/`) punya lapisan sendiri: `admin/src/lib/admin/appwrite.ts` + `admin/src/features/admin/*/services`.
- `00_BACKEND/src/services/*.ts` (+ salinan `.js`) adalah implementasi referensi/teruji (vitest di `00_BACKEND/tests`); frontend tidak mengimpornya — beberapa fungsi frontend menyebut dirinya "Mirror 00_BACKEND/src/services/...". (−) Dua salinan logika dapat menyimpang.
- Mutasi lintas-user dan finansial dipindah ke Appwrite Function (dipanggil service lewat `executeFunction`), karena permission baris tidak bisa dipasang browser untuk user lain dan field keuangan tidak boleh ditulis klien.
- Pelanggaran diketahui: `src/components/features/chatbot/ChatbotPanel.tsx` mengimpor `account` dari `@/lib/appwrite/account` secara langsung.
