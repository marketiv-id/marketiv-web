# ADR-001 — Gunakan Appwrite BaaS, Bukan Backend Custom

## Status

Diterima.

> **Catatan verifikasi 2026-10-12:** keputusan masih berlaku di kode. Dua penyesuaian implementasi dicatat di Consequences (TablesDB via REST mentah, dan chatbot AI di Next.js API route).

## Context

- MVP harus dibangun cepat oleh tim kecil (4 orang) dalam 12 minggu.
- Dibutuhkan auth, database, storage, realtime, dan logika server-side berbasis event.
- Membangun backend custom akan menambah beban infrastruktur dan waktu.

## Decision

Gunakan **Appwrite** sebagai BaaS untuk Auth, Database, Storage, Realtime, dan Functions. AI diakses lewat Appwrite Function wrapper.

## Consequences

- (+) Kecepatan pengembangan: fitur backend inti tersedia bawaan.
- (+) Realtime & event architecture didukung native (Functions + Events).
- (−) Bergantung pada kapabilitas & batasan Appwrite Cloud.
- Akses Appwrite tetap diabstraksi lewat service layer (lihat [ADR-002](ADR-002.md)).

### Catatan implementasi (2026-10-12)

- Server Appwrite 1.9.x memakai penamaan **TablesDB** (`tables`/`rows`). Seluruh event Function di `00_BACKEND/appwrite.config.json` berbentuk `databases.<db>.tables.<table>.rows.*.<aksi>`; `appwrite.config.json` adalah konfigurasi kanon (`appwrite.json` usang).
- Kode Function dan frontend masih memakai API Documents (`Databases.listDocuments/createDocument/updateDocument`, `node-appwrite@^14` dan `appwrite@^25`). Operasi yang tidak tersedia di SDK tersebut dipanggil lewat REST mentah ke endpoint `/tablesdb/...`:
  - increment/decrement kolom atomik dengan `min`/`max` (salinan `functions/*/src/atomic.js`) untuk `wallets.balance`, `campaigns.remainingBudget|spentAmount|totalClaims`;
  - transaksi database (`/tablesdb/transactions`) di `request-withdrawal/src/withdrawal-transaction.js` dan `review-withdrawal/src/withdrawal-transition.js`.
- (−) Karena deploy root Function adalah `functions/<id>/`, helper bersama diduplikasi per Function (`atomic.js`); pengecualian `create-conversation` dan `create-offer` yang di-deploy dari root `functions/` sehingga bisa mengimpor `functions/_shared/require-active-role.js`.
- AI: `ai-brief` dan `ai-fraud-precheck` adalah Appwrite Function (Gemini). Chatbot memakai **Next.js API route** `src/app/api/chat/route.ts` (Vertex AI, `@google-cloud/vertexai`) — penyimpangan dari "AI lewat Appwrite Function".
