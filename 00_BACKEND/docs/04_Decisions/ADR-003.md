# ADR-003 — `orders` sebagai Aggregate Utama Alur Rate Card

## Status

Diterima.

> **Catatan verifikasi 2026-10-12:** keputusan berlaku di kode. Satu-satunya pembuat order adalah `create-order` dari offer `accepted`; seluruh entitas finansial dan pengerjaan dikunci ke `orderId`.

## Context

- Alur Rate Card melibatkan offer, pembayaran, escrow, deliverable, dan revisi.
- Jika Offer mengelola Escrow langsung, tanggung jawab finansial dan status tersebar serta sulit dilacak.

## Decision

Jadikan `orders` sebagai aggregate utama. Offer tidak mengelola Escrow secara langsung. Alur:

```text
Offer → Order → Escrow → Deliverable → Revision → Completed
```

Order menjadi titik pusat status dan referensi finansial (escrow, deliverable, revisi).

## Consequences

- (+) Satu sumber kebenaran untuk status transaksi Rate Card.
- (+) Escrow dan deliverable terhubung jelas ke order.
- (−) Order harus dibuat sebelum escrow/deliverable diproses (langkah ekstra dari offer).

### Catatan implementasi (2026-10-12)

- `create-order` (event `offers.rows.*.update`) membuat `orders` `pending_payment` dengan `amount = offer.price` dan snapshot paket opsional; unique index `orders.idx_offerId` menjamin satu order per offer.
- Rujukan ke order: `payments.order_id` (+ lock unik `order_payment_key`), `escrows.orderId`, `deliverables.orderId`, `revisions.orderId`, `ratecard_deliverable_validations.orderId`; ledger pembayaran `transactions.referenceType = "order"`, sedangkan ledger rilis/fee/refund merujuk `escrow`.
- Status order (`pending_payment → in_progress ⇄ revision → completed | cancelled`) ditulis hanya oleh Function: `create-escrow`, `cancel-order`, `request-ratecard-revision`, `track-order-review`, `release-escrow`, `reconcile-release-escrow`. Tabel `orders` tanpa permission level koleksi.
- `create-offer` membaca state deal lewat offers → orders untuk menolak deal paralel di satu percakapan.
- (−) "Direct Order" tanpa offer tidak ada di kode; pemesanan paket tetap melalui offer (lihat [30_RateCard_Order](../03_Workflows/30_RateCard_Order.md)).
