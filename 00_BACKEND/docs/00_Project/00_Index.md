# 00_Project — Index

Folder ini berisi konteks tingkat proyek Marketiv: visi, ruang lingkup MVP, roadmap pengembangan, tumpukan teknologi, dan aturan kerja. Baca folder ini lebih dulu sebelum masuk ke `01_Global` atau modul.

## Daftar Dokumen

- [10_Vision.md](10_Vision.md) — Apa itu Marketiv, masalah yang diselesaikan, dan dua model bisnis: Campaign (Pay-Per-View) & Rate Card / Order (Escrow).
- [20_Scope.md](20_Scope.md) — Fitur yang masuk MVP dan yang dikecualikan.
- [30_Roadmap.md](30_Roadmap.md) — Urutan pengembangan 6 sprint / 10 fase + prioritas P0/P1/P2, plus status implementasi terkini per fitur.
- [40_Tech_Stack.md](40_Tech_Stack.md) — Tumpukan teknologi beserta versi aktual (Next.js 16 + React 19, Appwrite Cloud + Functions `node-22`, Vertex AI/Gemini/OpenRouter, Midtrans Snap, Zod 4, Tailwind 4 + shadcn/Radix, Sentry, Vitest/Playwright).
- [50_Project_Rules.md](50_Project_Rules.md) — Aturan kerja proyek (docs as source of truth, satu fakta satu lokasi, service layer wajib, sinkronisasi Function ↔ config).
